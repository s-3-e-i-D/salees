# سَلِس

كيبورد عربي وإنجليزي.

## ملف IPA

أجهزة ماك عند GitHub كانت ممتلية، فالبناء صار على [Codemagic](https://codemagic.io/signup) (٥٠٠ دقيقة مجانية على أجهزتهم):

1. ادخل بحساب GitHub واختر المستودع `s-3-e-i-D/salees`.
2. شغّل workflow اسمه **Salees IPA**.
3. نزّل `Salees.ipa` من الـ artifacts.
4. ثبّته بـ [SideStore](https://sidestore.io) أو [AltStore](https://altstore.io) وسجّل دخول بحساب آبل. التطبيق يعيش ٧ أيام على الحساب المجاني.

سَلِس يفتح كتطبيق لحاله، وما يستبدل كيبورد واتساب. من سفاري: مشاركة، ثم إضافة إلى الشاشة الرئيسية، وهذا يشتغل بدون IPA.
